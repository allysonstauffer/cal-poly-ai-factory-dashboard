# Progress update: 2026-11-12

## Done since Nov 6

- **Run:ai client** (`9108d5a`): caches the token in memory and retries once with a new token on HTTP 401. Refuses anything other than GET requests and the token request. Error messages and tracebacks have hostnames, IPs, and tokens removed, so they're safe to share.
- **Paginated fetch** (`src/workloads.py`): collects every page of `/api/v1/workloads`, with a safety limit on the number of pages and de-duplication by workload ID.
- **Summary script** (`5692b8d`, `src/summarize_workloads.py`): prints counts only: total, by phase, by type, unique submitters (a number, never names), requested and allocated GPUs. Field names live in one mapping so they're easy to fix.
- **Data dictionary** (`d529132`, `docs/data-dictionary.md`): about 40 workload fields from the Run:ai v2.25 docs, each with type, meaning, and a public-safe rating. Also explains allocated vs. utilized GPUs.
- **Tests**: 31 offline tests using fake data. They cover pagination, the 401 retry, error-message scrubbing, the summary output, and a check that no names appear in it.
