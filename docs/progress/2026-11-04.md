# Progress update: 2026-11-04

## Done

- **Project setup:** created the GitHub repo structure, the Python environment and dependencies, and initial docs (README, software requirements, data dictionary, architecture).
- **Run:ai API integration:** wrote an initial read-only Python client that authenticates with Run:ai and retrieves workload data.
- **Credentials:** real keys are kept in a local `.env`, which is git-ignored and has never been committed. The repo contains only the `.env.example` template.
- **Connectivity:** confirmed DNS resolution and an HTTPS connection to Cal Poly's Run:ai server on port 443.
- **TLS troubleshooting:**
  - The first API request failed certificate verification (`unable to get local issuer certificate`).
  - The server's certificate is issued by the Cal Poly AI Cluster Local CA, which the Python environment doesn't trust by default.
  - Added optional `RUNAI_CA_BUNDLE` support so the client can verify against that CA with TLS verification still on (`78735ae`).
  - Certificate files are git-ignored, and the setting is documented in `.env.example` and the README.
